# Mohammed Nisar Ahmed — Portfolio

A responsive single-page portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools or package installation are required. Google Fonts are loaded from the web; system fallbacks are included.

## Customize
- Update content and links in `index.html`.
- Change the violet accent and other design tokens at the top of `style.css`.
- Animation and mobile navigation behavior are in `script.js`.
